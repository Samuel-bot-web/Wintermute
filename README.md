# Wintermute

Privater Homeserver / Homelab-Server auf Proxmox VE.

Siehe [`docs/00-Projektuebersicht.md`](docs/00-Projektuebersicht.md) für den
aktuellen Projektstand und alle Details.

## Struktur

- `docs/` – Laufende Dokumentation (Hardware, Netzwerk, Storage, Backups, Sicherheit)
- `stacks/` – Docker-Compose-Konfigurationen aller Dienste
- `scripts/` – Automatisierungs-Skripte (Backup, etc.)
